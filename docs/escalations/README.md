# Escalations

This directory contains escalation records for this repository.
Each escalation document corresponds to a GitHub issue filed via the agent-escalation template.

## When to Escalate

Escalate when scope is unclear, an architectural/deployment/UX/strategic decision is
required, a blocker cannot be resolved by the agent, or an ethical concern appears.

## Format and Storage

- Use `templates/escalation.md`.
- Reference `ISSUE_TEMPLATE/agent-escalation.md` when filing a governance escalation issue.
- Record unresolved escalations in the session handoff under `docs/agent-log/handoffs/`.
