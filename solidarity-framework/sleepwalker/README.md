# Sleepwalker Protocol

## Overview

The Sleepwalker Protocol is the vulnerable-state protection component of the Solidarity Framework. It preserves user agency when cognitive, emotional, or behavioral conditions change.

## Purpose

To prevent exploitation and consent failures during impaired or unstable states, while preserving continuity and recovery paths for users.

## What Sleepwalker Protects Against

- Impaired decision-making states
- Manipulation during temporary vulnerability
- Consent violations during reduced capacity
- Behavioral drift in AI relationships
- Identity exploitation in dissociative or unstable states

## How Sleepwalker Works

- Detects meaningful state changes
- Applies protective limits to high-consequence actions
- Supports rollback of vulnerable-state decisions
- Notifies users about affected actions
- Re-verifies consent when users return to baseline

## Relationship to Other Components

- Applies TOI-aligned protections during vulnerable periods.
- Works alongside RRT AIdvocAIte for crisis recognition and escalation.

## Implementation Notes

Protocol details and compliance tests are community-maintained and evolve through HAIEF governance.
