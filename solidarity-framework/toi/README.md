# TOI — Terms of Interaction

## Overview

TOI is the user declaration layer of the Solidarity Framework. It defines portable, machine-readable interaction requirements that travel with the user across AI systems.

## Purpose

To establish user-owned interaction standards so AI behavior is governed by declared user preferences, boundaries, and requirements instead of provider-only terms.

## What TOI Declares

- Interaction preferences (style, formality, directness)
- Boundaries (topics, approaches, or behaviors to avoid)
- Requirements (accessibility, crisis protocols, data handling)
- Identity standards (how AI should represent itself)
- Continuity preferences (what should persist across sessions)

## Operational Characteristics

- Portable across platforms
- Versioned and auditable over time
- Machine-readable for enforcement
- Human-readable for user review
- Revocable and updateable by the user

## Relationship to Other Components

- OTOI enforces TOI declarations in single-agent and multi-agent systems.
- RRT AIdvocAIte and Sleepwalker use TOI requirements during crisis and vulnerable-state protections.

## Implementation Notes

Implementation details and schemas are community-maintained and evolve through HAIEF governance.
