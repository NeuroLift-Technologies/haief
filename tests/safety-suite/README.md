# HAIEF Safety Test Suite

## Overview

This directory contains safety tests for HAIEF-compliant AI systems.

## Purpose

To validate that AI systems implementing HAIEF standards meet safety requirements for:

- Human-safe interactions
- Emotional continuity
- Identity integrity
- Provenance tracking
- Safe multi-agent handoffs
